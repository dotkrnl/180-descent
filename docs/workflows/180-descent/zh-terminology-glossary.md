# Chinese Terminology Glossary

This is the authoritative Simplified Chinese terminology glossary for
180 Descent translation work.

Kimi, Gemini, GLM, and any human/editorial pass must:

- read this file before editing Chinese content;
- apply the standard Chinese term unless a local exception is explicitly
  justified by the prose or source title;
- update this file in the same change when a repeated course term is missing,
  newly standardized, or found inconsistent;
- fix inconsistent usages in touched files when practical.

When two English terms represent different concepts, do not collapse them into
one Chinese word. This matters especially in physics and frontier appendices.
