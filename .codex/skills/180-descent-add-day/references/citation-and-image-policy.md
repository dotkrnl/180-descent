# Citation And Image Policy

## Citations

Use numbered end sources in the lesson's `section.sources`.

Fact-check every factual claim, quote, citation, DOI, URL, date, result, and reference by web search before keeping it in the lesson. Prefer primary or official pages for verification; use secondary sources only when they add necessary context. Make sure each source supports the nearby claim, and remove or rewrite claims that cannot be verified.

Verify direct quotes against the original publication, transcript, archive scan, or another reliable reproduction. If wording cannot be verified exactly, paraphrase instead of using quotation marks.

Prefer:

- primary papers
- official project pages
- Stanford Encyclopedia of Philosophy for philosophy background
- peer-reviewed review articles
- official documentation or institutional releases for data projects

For frontier claims:

- label weight as established, promising hint, or contested/hype
- include dates for fast-moving claims
- include sigma and dataset for physics/cosmology claims
- reject future-dated arXiv IDs

## Images

Prefer, in order:

1. Original diagrams built in SVG/HTML/CSS.
2. Open-license figures, public-domain images, or Creative Commons images with local copies and attribution when they clarify the lesson.
3. Official-source images where reuse is clearly allowed.
4. Generated bitmap images when copyright-safe external images are not suitable.

Update `src/_data/credits.yaml` for every added asset.

Do not hotlink images from external sites.

Before adding an external figure, verify the license on the source page and capture enough credit data for attribution: creator, title or description, source URL, license name/version, and whether the image was modified. Do not add decorative open-license images just because they are available; use them when they make the text clearer, more concrete, or more memorable.
