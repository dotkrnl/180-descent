# Citation And Image Policy

## Citations

Use numbered end sources in the lesson's `section.sources`.

Prefer:

- primary papers
- official project pages
- Stanford Encyclopedia of Philosophy for philosophy background
- peer-reviewed review articles
- official documentation or institutional releases for data projects

For frontier claims:

- label weight as established, promising hint, or contested/hype
- include dates for fast-moving claims
- include sigma and dataset for physics/cosmology claims
- reject future-dated arXiv IDs

## Images

Prefer, in order:

1. Original diagrams built in SVG/HTML/CSS.
2. Public-domain or Creative Commons images with local copies and attribution.
3. Official-source images where reuse is clearly allowed.
4. Generated bitmap images when copyright-safe external images are not suitable.

Update `src/_data/credits.yaml` for every added asset.

Do not hotlink images from external sites.
